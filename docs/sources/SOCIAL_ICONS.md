# Социальные иконки

Монохромные SVG в фирменных синих кнопках: `prototype-mobile/assets/local/{max,telegram,dzen,youtube,vk,ok}.svg`. Оригиналы: `design-assets/brand/social-monochrome/`. MAX — векторный.

Источники: [MAX](https://go.max.ru/brandbook), [Telegram](https://telegram.org/tour/screenshots), [Дзен](https://dzen.ru/about/download), [YouTube](https://brand.youtube/youtube-icon/), [VK](https://vk.com/brand), [Одноклассники](https://insideok.ru/brandbook).

Размеры и цвет кнопок заданы стилями `social-links` и его вариантов. Сохранять пропорции логотипов, в Figma использовать экземпляры компонентов иконок.
