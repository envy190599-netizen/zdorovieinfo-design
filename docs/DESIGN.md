# Согласованные правила компонентов

Имена компонентов в Figma и CSS одинаковые, в kebab-case. Точные размеры и адаптивные значения заданы в CSS; состояния и варианты показаны в Figma.

## Шрифт и цвета

Везде Montserrat, локальный WOFF2. Основной текст #003B5D, брендовая кнопка #137DB8, ошибка/акцент #D02055; нейтральный placeholder #757575. Токены: `styles.css`, `typography.css`.

| Роль | Desktop | Mobile / меньшие экраны |
| --- | --- | --- |
| Заголовок открытой статьи, «Моя лента», «Телевидение» | 600, 44px / 1.1 при ≥1024px | 600, 28px / 1.1 |
| Заголовок карточки материала, включая широкую | 600, 16/20px | 600, 21/25px при <768px |
| Заголовок карточки «Сейчас читают» | 500, 14/20px | 500, 14/20px |
| Заголовок строки «Главное за неделю» | 500, 18/25px | 500, 16/22px |
| Заголовки блоков «Сейчас читают», «Главное за неделю», «Специально для вас» | 600, 18/24px | тот же |

В карточке врача названия полей полужирные (600), значения Regular (400); имя и названия полей основным тёмно-синим, роль врача вторичным цветом. Не делать описание ТВ-выпуска целиком полужирным.

## Карточки, панели и изображения

- На мобильном одна карточка материала в строке, отступ между карточками 20px, текстовые поля 20px. Обычная и широкая карточки используют одну роль заголовка. Мобильный заголовок переносится по содержимому без desktop-обрезки.
- Desktop-карточки в редакционной сетке имеют широкую позицию через каждые пять элементов. Не менять заданные размеры текстовых областей только из-за короткого текста: они выравнивают строки сетки.
- «Сейчас читают»: максимум две строки заголовка, затем многоточие; подпись только типа материала («Статья» и т. п.), без тематики. Превью 64×64px. Не осветлять изображение при наведении.
- «Главное за неделю»: мобильное превью 72×72px; desktop 88×66px. Сначала 5 материалов, «Показать ещё» раскрывает оставшиеся. Общий предел текущего списка — 10.
- На мобильном «Сейчас читают» и библиотека заболеваний присутствуют только на главной и в «Моей ленте». Библиотека идёт после «Главного за неделю».
- У «Специально для вас» общая белая обёртка заголовка и горизонтальной подборки. У вводных блоков ленты и ТВ белая карточка заголовка отделена от карточек материалов.
- Бейдж типа материала: белый фон, тонкая серо-синяя обводка #E3EFF6, без тени.
- Обложки инфографик — тематические фото; сам большой плакат показывается на странице материала. Не использовать фрагмент текста плаката как превью.
- Изображение кадрируется через object-fit: cover, не деформируется. Медиа-контейнер определяет размер и скругление; масштабируется только вложенное изображение.

## Наведение и движение

Только для мыши/точного указателя: приближение фото 1.04 за 320ms, cubic-bezier(0,0,0.2,1) у карточек, где оно предусмотрено кодом, включая недельную подборку. Контейнер неподвижен и обрезает фото. На touch hover-эффекты отключены. Сохранять клавиатурный focus-visible. При prefers-reduced-motion отключать лишнюю анимацию. Закрытие бургера — обратное открытию.

## Хедер, бургер и первый экран

- Мобильный хедер на всю ширину, без скруглений, закреплён сверху и не прыгает при скролле. Высота текущего хедера 72px.
- Логотип и переключатель меню/закрытия остаются в тех же координатах при открытии. Поиск занимает доступное место в той же верхней строке; раскрывается по ширине.
- Темы размещены в бургере единым списком с равномерными интервалами. Без пункта «Главная», старого дубля тем и формы подписки. Три акцентных пункта без отдельного большого отступа и белой обводки.
- Кнопка «Спецпроекты» в фирменном синем стиле; иконки под ней, одна строка на всю ширину, space-between. Телевидение представлено иконкой. У поиска, меню и закрытия единая оптика и размер области действия.
- Управляющие и социальные иконки векторные, MAX не PNG. Отдельная 3D-навигация — согласованные растровые иллюстрации, не подменять их управляющими SVG.
- Мобильный первый экран сохраняет слайдер. Превью горизонтальные 16:9 и должны помещаться вместе с ним в видимой области; допускается заход изображения под закреплённый хедер. Точный расчёт высоты и safe-area брать из fullscreen-home.css/responsive-layout.css, не задавать всем устройствам фиксированную высоту скриншота.

## Футер и подписка

Футер в общей белой скруглённой карточке без обводки. Левая колонка (лого, текст, иконки) растягивается на высоту подписки и распределяет блоки по вертикали. Подписка по ширине содержимого, с внутренними полями; input заполняет доступную ширину. Внутренний gap подписки 10px. У ссылок футера одинаковый горизонтальный и вертикальный gap 20px, перенос строк естественный.

Подписка: пустое поле / ввод / ошибка / успех. Нет состояния «Отправляем». Ошибка — введённый текст красным, без видимой подписи под формой. Успех — «Готово! Спасибо за подписку.» внутри readonly-input. На desktop стрелка появляется только при вводе, исчезает после успеха; на мобильном стрелки нет, отправка Enter. Высота блока не меняется при ошибке/успехе. Скрытый live-status остаётся доступен скринридеру. Текущая форма — демонстрация, реальная отправка не подключена.

## Телевидение

Фокус поиска и дропдаунов обозначается обводкой 2px цвета var(--blue), #137DB8, с offset 2px. Тёмный/чёрный outline не использовать; размеры поля при фокусе неизменны. Клавиатурные контролы фильтров используют тот же голубой цвет.

Переключатель сетка/список справа от текстового поиска, в одной строке. Его внутренние поля одинаковы по всем сторонам: 5px при ширине ≥1280px, 2px ниже этого порога. На мобильном «Здоровье» и «Жить здорово!» в первой строке, «Все программы» на всю следующую строку. Сброс фильтров стандартной синей кнопкой.

В списочной карточке программа, дата и название выпуска идут единым текстом одного стиля, вертикально по центру рядом с картинкой. Не возвращать разнесённые верхний заголовок и нижнюю строку метаданных. Внутри выпуска описание обычным стилем основного текста статьи.

## Figma

Все компоненты и вложенные контейнеры — подходящий Auto Layout, без Freeform для раскладки. Иконки и повторно используемые элементы внутри других компонентов — экземпляры соответствующих компонентов. Не detaching ради исправления текста. Возможны абсолютные декоративные/медиа-слои внутри Auto Layout.

Заголовок экземпляра наследует типографику мастера: горизонталь Fill, высота Auto height, перенос по доступной ширине. Desktop-ограничение строк наследовать от мастера. Не задавать текстовым блокам ручные координаты и Auto width вместо переноса по ширине.

Компоненты сгруппированы по семействам горизонтально на отдельных страницах, общая страница содержит компоненты и экраны. Повторяемые элементы сохраняют связь с мастером.
