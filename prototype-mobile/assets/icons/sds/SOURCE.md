# Simple Design System view icons

Original SDS grid/list artwork, retrieved 2026-09-18.

- Grid: https://github.com/figma/sds/blob/main/src/ui/icons/IconGrid.tsx
- List: https://github.com/figma/sds/blob/main/src/ui/icons/IconList.tsx
- Retrieved 2026-09-18. Original path geometry and 1.6 stroke retained; TSX wrapped in a standalone 16 × 16 SVG and the stroke variable replaced with currentColor. Rendered as a CSS mask for inherited active/inactive colors.
- No React runtime or third-party icon package added. These are upstream SDS assets, not exports claimed from the local ZI file.
