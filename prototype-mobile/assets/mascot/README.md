# Иллюстрация помощника

Статический исходник `malysheva-v3.png`: 1024×1536 RGBA. Анимированный экспорт `malysheva-idle-v1.webp`: 256×384, 122 кадра, около 5 секунд, бесконечный цикл, прозрачность. Изображения декоративные; логику персональной подборки реализует feed-assistant.js.

Общий site-components.js выбирает анимацию только при prefers-reduced-motion: no-preference; иначе PNG. Мобильная кнопка помощника и отображение иллюстрации регулируются адаптивными стилями. Не растягивать пропорции, сохранять альфа-канал и safe-area. На главной появление ограничено прокруткой до недельной подборки; оверлеи скрывают иллюстрацию.

Референс внешности: https://hubspeakers.ru/bio/malysheva . Исходная референсная фотография в поставку не входит. Это иллюстративный UI-ресурс, не редакционная фотография.
