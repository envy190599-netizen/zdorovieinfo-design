# Исходники 3D-иконок навигации

13 самостоятельных растровых иллюстраций; это не SVG. Исходные листы: `topics-generated.png`, `projects-generated.png`; координаты извлечения: `exports.json`. Готовые PNG 256×256 с альфа-каналом: `prototype-mobile/assets/local/navigation-3d-v2/`.

Сохранять прозрачность, центрирование, равномерные внутренние поля и читаемость на 28 CSS px. Не добавлять белую подложку, не растягивать пропорции и не допускать соседних фрагментов листа. Логотипы социальных сетей и управляющие иконки передаются отдельно в SVG.
