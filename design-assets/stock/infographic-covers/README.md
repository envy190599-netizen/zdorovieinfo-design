# Обложки инфографик

В карточках — тематические фотографии. Полная инфографика отображается на странице материала. Обложка «Как устроено сердце» — фотография стетоскопа.

| Тема | Обложка | Автор / источник |
| --- | --- | --- |
| Кто может стать донором | Красное сердце в руке, светлый фон | teksomolika, Freepik / Magnific |
| Здоровье между донациями | Пробежка в парке | Jeremy Stewart, ранее сохранённый Unsplash |
| Рацион перед донацией | Чай, тосты, джем | boyarkinamarina, Freepik / Magnific |
| Питание между донациями | Рыба, крупа и овощи | Ella Olsson, ранее сохранённый Unsplash |
| Лейкоз | Микроскоп и пробирки на белом фоне | magnific, Freepik / Magnific |
| Отсутствие сна | Спящий человек на белой подушке | rawpixel.com, Freepik / Magnific |
| Нормы давления | Электронный тонометр с манжетой | suksao, Freepik / Magnific |

Страницы оригиналов и авторство — в [sources.json](sources.json) и [общем реестре](../ATTRIBUTION.md).

Обложки: `prototype-mobile/assets/editorial/static-infographics/*-cover.webp`, максимальная сторона 1920 px. Кадрирование выполняет карточка.

В `static-infographics/sources.json` поля `source`, `original` и `sha256` относятся к самой инфографике; `coverSource`, `coverAuthor`, `coverProvider` — к обложке.
