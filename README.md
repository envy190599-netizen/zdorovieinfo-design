# Здоровье инфо

[Макеты и компоненты в Figma](https://www.figma.com/design/vMQvJr6wdwZi8tHPxZBa4q/ZI-DEV)

- `prototype-mobile/` — код всех экранов сайта: desktop, tablet и mobile. `components.html` — библиотека компонентов.
- [Правила дизайна](docs/DESIGN.md) — типографика, адаптив, состояния и ограничения компонентов.
- [Исходники](docs/ASSETS.md) — иконки, шрифты, изображения и ссылки на оригиналы; дополнительные ресурсы в `design-assets/`.

Имена компонентов в Figma совпадают с их CSS-классами: `material-card`, `week-digest`, `view-switch` и остальные. Варианты обозначают состояния и размеры одного компонента.
